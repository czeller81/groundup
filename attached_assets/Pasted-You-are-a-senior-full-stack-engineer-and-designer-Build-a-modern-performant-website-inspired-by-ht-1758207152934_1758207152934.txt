You are a senior full-stack engineer and designer. Build a modern, performant website inspired by https://groundupbjj.com/
 for a Brazilian Jiu-Jitsu academy named “Ground Up BJJ.” The site must support personal training appointment booking + online payment.

Tech stack

Next.js 14 (App Router) + TypeScript

Tailwind CSS for styling (clean, modern, mobile-first)

Prisma + SQLite (switchable to Postgres via DATABASE_URL)

Stripe for payments (Stripe Checkout + Webhooks)

NextAuth (Credentials provider) for an admin user to manage bookings

Resend (or Nodemailer SMTP) for email confirmations

Core requirements

Pages / sitemap

/ Home: hero, value props (self-defense, conditioning, discipline), CTA buttons: “Book Personal Training” + “Free Intro”

/personal-training Booking page with calendar, session options, pricing, trainer bio, FAQs, testimonials.

/coaches Coach bios (photo, belt rank, specialties).

/pricing Clear plans (drop-in, 5-pack, 10-pack, monthly PT).

/contact Contact form (send email), map embed, hours, phone, address.

/admin Protected dashboard for viewing/updating bookings + exporting CSV.

Booking flow (PT only)

Session types:

60-min 1:1 ($120),

90-min 1:1 ($160),

Small group (2–4) 60-min ($180 total).

Calendar with trainer availability (simple availability table; prevent double-booking).

Select date/time → collect name, email, phone, notes → Stripe Checkout payment.

After successful payment, create Booking record, send email receipt + confirmation with ICS calendar invite.

Admin can manually add/edit/cancel bookings; cancellations trigger refund flow stub (no automatic refunds, just admin note).

Data models (Prisma)

model Trainer {
  id        String   @id @default(cuid())
  name      String
  bio       String
  photoUrl  String
  specialties String[]
  availability Json   // e.g. { "Mon":[ "10:00","12:00" ], "Wed":[ "18:00" ] }
  createdAt DateTime @default(now())
}

model Booking {
  id           String   @id @default(cuid())
  customerName String
  customerEmail String
  customerPhone String
  notes        String?
  sessionType  String   // "PT60" | "PT90" | "GROUP60"
  start        DateTime
  end          DateTime
  trainerId    String
  trainer      Trainer  @relation(fields: [trainerId], references: [id])
  amountCents  Int
  currency     String   @default("usd")
  stripeSessionId String
  status       String   // "pending","paid","canceled","refunded"
  createdAt    DateTime @default(now())
}

model AdminUser {
  id       String @id @default(cuid())
  email    String @unique
  password String
  createdAt DateTime @default(now())
}
