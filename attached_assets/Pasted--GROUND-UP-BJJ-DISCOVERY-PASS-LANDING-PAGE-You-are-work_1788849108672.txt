# GROUND UP BJJ — DISCOVERY PASS LANDING PAGE

You are working inside the existing Ground Up BJJ website/application.

Your task is to create and integrate a dedicated **Discovery Pass landing page** for a new paid advertising campaign.

This is a production-facing marketing and onboarding page.

## PRIMARY GOAL

Create a high-converting Discovery Pass landing page that feels completely native to the existing Ground Up website.

The page must preserve the site's current:

* visual identity
* typography
* colors
* spacing
* navigation conventions
* buttons
* mobile behavior
* layout patterns
* tone of voice
* existing components where possible

Do **not** create a separate-looking microsite.

Do **not** introduce a new visual design system.

The finished page should look as though it has always been part of the Ground Up website.

---

# 1. FIRST AUDIT THE EXISTING SITE

Before making changes, inspect the existing Ground Up public website and determine:

* current design system
* global styles
* typography
* colors
* header/navigation
* footer
* button styles
* card styles
* responsive breakpoints
* English/Spanish localization implementation
* authentication/signup flow
* member portal
* Discovery Pass or trial-related logic already present
* waiver workflow
* class-booking workflow
* analytics/event tracking already implemented

Reuse existing components and patterns whenever possible.

Do not duplicate functionality that already exists.

---

# 2. LANDING PAGE PURPOSE

This page exists for one conversion:

**Get a visitor to claim the free Ground Up Discovery Pass.**

The advertising campaign will contain:

1. English video ad
2. Spanish video ad

Both should lead into the appropriate language version of this page.

The user journey is:

AD
→ DISCOVERY PASS LANDING PAGE
→ CREATE ACCOUNT
→ SIGN REQUIRED WAIVERS
→ ACTIVATE DISCOVERY PASS
→ BOOK CLASSES
→ ATTEND CLASSES
→ MEMBERSHIP CONVERSION

The landing page should not overwhelm the user with the entire backend process.

Its job is primarily to make the Discovery Pass easy to understand and compelling enough to claim.

---

# 3. DISCOVERY PASS OFFER

The Discovery Pass should clearly communicate:

**Free Discovery Pass**

Includes:

* 1 SKILL class
* 1 STRENGTH class
* 7 days to use the pass after activation

Use the actual Ground Up terminology already used by the application.

If production logic differs from these assumptions, do not silently change production behavior.

Instead:

1. inspect the existing implementation,
2. report the discrepancy,
3. preserve existing business rules unless explicitly authorized to change them.
