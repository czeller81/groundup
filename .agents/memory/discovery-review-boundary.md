---
name: Discovery duplicate review boundary
description: Shared contact details alone should not block a new Discovery Pass request.
---

A matching phone number is not sufficient evidence for Discovery Pass admin review. Review remains appropriate when the same user already has qualifying prior use or another account with that phone has already claimed a Discovery Pass.

**Why:** Guardians, households, and controlled QA accounts can legitimately share phone numbers; treating the phone match alone as a duplicate blocked valid new-member activation.

**How to apply:** Preserve the existing pass uniqueness and prior-use checks, but do not reintroduce phone-only review without a clear product decision.
